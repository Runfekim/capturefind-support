CapStack 지원

쌓아 둔 스크린샷을, 필요한 순간에.

CapStack는 스크린샷 속 글자를 기기 안에서 인식해, 키워드로 다시 찾을 수 있게 해 주는 앱입니다.

자주 묻는 질문

스크린샷이 검색되지 않아요

먼저 인덱싱이 끝났는지 확인해 주세요. 홈 화면의 인덱싱 카드나 위젯에서 아직 처리되지 않은 개수를 볼 수 있습니다. 사진 접근 권한이 제한됨으로 되어 있으면 선택한 사진만 읽을 수 있으니, 설정 → CapStack → 사진에서 전체 접근으로 바꿔 주세요.

사진 접근 권한은 왜 필요한가요

스크린샷에서 텍스트를 읽어 오기 위해 필요합니다. 글자 인식은 기기에서 이뤄집니다. AI 분석에 동의하면 인식된 텍스트를 TypeSafe JEV에 전송합니다. 원본 이미지는 전송하지 않습니다.

iPhone 검색(Spotlight)에 나오게 하려면

인덱싱이 끝난 스크린샷은 자동으로 시스템 검색에 포함됩니다. 홈 화면을 아래로 스와이프해 검색해 보세요.

스크린샷을 찍자마자 저장하려면

스크린샷을 찍으면 좌하단에 미리보기가 뜹니다. 탭 → 우상단 공유 → CapStack → 폴더를 고르면 앱을 열지 않고 바로 담깁니다.

위젯 추가

홈 화면이나 잠금화면을 길게 누르고 위젯에서 CapStack를 추가하면, 아직 인덱싱하지 않은 개수가 바로 보이고 탭 한 번으로 인덱싱이 시작됩니다.

Siri로 실행하기

“헤이 Siri, 스크린샷 인덱싱”이라고 말해 보세요.

CapStack Pro

Pro를 구독하면 AI 분석을 장수 제한 없이 사용할 수 있고 정리 순서를 직접 고를 수 있어, 최신 스크린샷뿐 아니라 오래 묵은 스크린샷부터 차례로 정리할 수 있습니다. 확대·자르기, 보관함 정렬 같은 기본 기능은 Pro 없이도 계속 사용할 수 있습니다.

구독 관리·해지

구독은 기간이 끝나기 24시간 전까지 해지하지 않으면 자동으로 갱신됩니다. 설정 → Apple 계정 → 구독에서 언제든지 해지할 수 있습니다. 결제와 환불은 Apple이 처리하며, 환불은 reportaproblem.apple.com에서 요청할 수 있습니다.

기기를 바꾸었거나 앱을 다시 설치했다면, 페이월 화면의 구매 복원을 눌러 주세요.
